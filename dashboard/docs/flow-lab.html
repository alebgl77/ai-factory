    02 / Exécution

    Injecter un scénario

    Mesures estimées

    Trajet et contrôles

        Méthode de calcul et règles de routage
        • Chaque demande d’un lot partage le même scénario. Les compteurs et le coût sont multipliés par le nombre de demandes.
        • Pour C3/C4, un routeur privilégie la liaison sensible si elle existe. Un modèle distant simulé bloque toujours ces classes, même si aucune passerelle ne précède le modèle.
        • Une panne peut déclencher le repli du dernier routeur. Une tentative indisponible ajoute du délai et ne consomme aucun token. Un blocage de sécurité termine le trajet.
        • La latence représente un trajet unitaire estimé à partir de délais fixes et d’un débit de tokens fictif. Le modèle n’inclut ni attente en file ni concurrence réelle.
        • Un nœud de recherche ajoute des tokens d’entrée simulés. Chaque modèle facture ses propres tokens selon un barème fictif.
